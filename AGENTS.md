# AGENTS.md

- После успешного выполнения каждой законченной задачи и прохождения релевантных проверок обязательно делай `git commit`.
- Перед каждым коммитом обязательно запускай `npm run format:check`; если Prettier находит проблемы, исправляй форматирование и повторяй проверку до успешного результата.
- Сообщение коммита должно быть на русском языке и соответствовать Conventional Commits.
- Если работаешь с файлом `docs/frontend-inbox.md` в backend-проекте, удаляй из него только те инструкции, которые уже выполнены во frontend.
